# 节奏训练室 · Rhythm Lab v1.0

兼容 iPhone Safari、PC 浏览器的节拍与节奏训练网页。**无需账号，无需外部库，不收集数据。**

## 如何使用

### 在电脑本地运行

直接双击 `index.html`，使用浏览器打开。按页面上的「试听节拍」检验音量。空格键或鼠标点击绿色点击板打拍子。

### 在 iPhone 上运行（推荐 GitHub Pages）

1. 新建 GitHub 仓库，把本压缩包里的 **所有文件** 上传到仓库根目录（不要把整个 ZIP 直接上传）。
2. 在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**；Branch 选择 `main`，Folder 选择 `/(root)`，保存。
3. 打开 GitHub Pages 给出的 HTTPS 地址（通常是 `https://用户名.github.io/仓库名/`），在 Safari 中运行。
4. 可通过 Safari「分享 → 添加到主屏幕」安装成独立网页；初次联网打开后支持离线访问。

在 iOS「文件」App 里预览 `index.html` 不保证音频、离线缓存、存储能正常工作，建议用网页地址访问。手机请尽量使用内置扬声器或有线耳机；蓝牙耳机延迟波动较大。

## 训练模式

- **① 跟随节拍**：预备一小节 → 四小节有声跟拍 → 自动评价。
- **② 静音保持**：预备一小节 → 两小节有声引导 → 两小节完全静音（评分段）→ 一小节有声恢复。静音段不显示拍子进度，避免视觉作弊。
- **③ 节奏视读**：两小节五线谱，包含音符和休止符；预备一小节后无声点击（不播放答案）。音符都是五线谱中央 B4，训练重点仅为节奏。基础与进阶两档，支持 3/4 和 4/4。

**建议**：从 60–80 BPM 开始，点击“校准点击偏移”并稳定跟随 3 小节，然后按顺序完成三种练习。后续可逐渐提高速度、改用进阶节奏或 3/4。

## 评分说明

- 每个应敲击拍点与实际点击做顺序一致的一对一匹配。
- 命中率 = 匹配数 / 应敲击数；多余点击与遗漏分别记录。
- 平均绝对时间偏差（MAE）只对匹配成功的点击计算；**不能单独看 MAE，必须同时看命中率和多击次数**。
- 正误差＝偏晚；负误差＝偏早。匹配容许窗口随 BPM 和最短节奏间隔调整，具体窗口显示在结果中。
- 校准以稳定跟拍时的误差中位数修正统一偏移。校准值可能同时包含音频设备、触摸设备、个人反应与演奏习惯，**不等同于纯设备延迟**。
- 触屏、键盘与音频输出各有延迟，页面无法进行实验室级绝对时序测量，特别不建议用蓝牙耳机作毫秒精度比较。

## 使用限制和数据

- Web Audio 预排程（每 25ms 提前调度约 140ms 的音频），减少常规 JS 计时抖动对播放的影响。
- 练习时切换后台会中止当前轮次，避免时序失真；iOS 请保持屏幕点亮。
- 浏览器本地保存最多 200 次历史记录，可导出 CSV；清除网站数据或使用无痕模式可能丢失历史。
- 首次启动需要手动点击开始，以便 iPhone Safari 解锁音频。
- 节奏谱使用简化的手绘记谱，不是专业乐谱排版引擎；训练仅针对音符起点（onset），不评估按住的时值或小提琴运弓。休止符正确理解以静默处理、不能点击来体现。
